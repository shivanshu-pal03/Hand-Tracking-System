# Hand Tracking System Using OpenCV and MediaPipe

## About the Project
This project uses computer vision to detect and track hand movements in real time using OpenCV and MediaPipe.

## Features
- Real-time hand tracking
- Detection of 21 hand landmarks
- Finger counting
- Gesture recognition
- Two-hand detection
- Wrist position tracking
- FPS display
- Smooth position tracking

## Technologies Used
- Python
- OpenCV
- MediaPipe
